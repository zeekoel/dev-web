# 🏦 Atlas Bank - Plateforme Bancaire Digitale

Atlas Bank est une interface web moderne et responsive pour une institution bancaire fictive basée au Maroc. Le projet met l'accent sur une expérience utilisateur fluide, une sécurité visuelle (thème sombre/bleu marin et violet) et une gestion complète des services bancaires en ligne.

## 🚀 Fonctionnalités actuelles

* **Accueil (acceil.html)** : Présentation des services principaux (Comptes, Crédit, Assurances).
* **Offres (offres.html)** : Catalogues des solutions adaptées (Étudiants, Immobilier, Marocains du Monde).
* **Transactions (transaction.html)** : Historique détaillé des opérations avec badges de statut et filtres.
* **E-Banking (E-banking.html)** : Tableau de bord client avec solde en temps réel et menu latéral.
* **Espace Entreprise (user.html)** : Double interface Connexion / Inscription pour les professionnels (ICE).
* **Contact (contact.html)** : Formulaire de support et informations de localisation.

## 🛠️ Technologies utilisées

* **HTML5** : Structure sémantique des pages.
* **CSS3** : Design moderne avec Flexbox, CSS Grid, et Variables natives (`:root`).
* **Design** : Approche "Mobile-First" avec Media Queries pour la réactivité.
